# kurenn.dev

Abraham Kuri's personal site: a belief about AI, the systems built toward it, and an invitation to talk.

Static HTML + Tailwind CDN + vanilla JS, served by GitHub Pages. Content lives in `js/data.js`; design notes in `_internal/DESIGN.md` and `_internal/PRODUCT.md`.

Run locally: `python3 -m http.server 8000`

Live at: [kurenn.dev](https://kurenn.dev)
