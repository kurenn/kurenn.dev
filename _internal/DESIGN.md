# DESIGN — kurenn.dev

The personal site shares the visual language of blog.kurenn.dev: a quiet Tokyo Night terminal, technical and readable rather than decorative.

## Palette

Ground `#1a1b26`, ink `#c0caf5`, body and metadata `#a9b1d6`, blue `#7aa2f7`, violet `#bb9af7`, green `#9ece6a`, red `#f7768e`, selection `#292e42`. Dim `#565f89` and muted `#414868` are decorative only, never for necessary text. Form errors use red.

## Type and layout

Use the blog's system monospace stack, no external fonts. A centered 44rem column holds the navigation and content, with the repo listing allowed more room where needed. Square tiles have a 2px blue border. Navigation links use brackets; the footer is quiet but legible. Small text headers on inner pages link home.

## Motion and signature

The home KURENN block logo uses the blog's blue-to-violet gradient, decrypt animation, and fit-to-width treatment. A field of pixels occupies the side margins on wide screens only. The manifesto opens as an accessible overlay with reading progress. Reduced motion disables decrypt, pixel shimmer, overlay fades and view transitions.
